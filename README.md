ThinkHire – AI-Powered Resume Screening System

ThinkHire is a web application that helps recruiters and HR teams efficiently screen and rank candidates using AI-based semantic matching.
ThinkHire is built with Flask on the backend, modern HTML/CSS for the UI, and NLP models (Sentence Transformers & spaCy) for intelligent resume analysis.

The platform allows users to sign up and log in securely, upload a job description along with multiple resumes, and receive ranked candidate results based on skills, experience, and semantic similarity.
